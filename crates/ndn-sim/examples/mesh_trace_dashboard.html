A multi-node trace, with the radio decision inside it

A distributed trace of 14 named fetches across a 4-node radio chain — each request's Interest walks up to the producer and the Data walks back, every hop a span on its node's lane, stitched to its causal parent. The point isn't just the waterfall: each Data hop carries the bandit's decision — the arm, MCS and power it chose — so "why did this node send at this rate" lives in the trace, not beside it. Hover any span.
