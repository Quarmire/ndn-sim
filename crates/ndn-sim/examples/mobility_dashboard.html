ndn-sim · mobility study #70

Statelessness vs route repair, under motion

N nodes roam a disc under RandomWaypoint; each half-second we rebuild the in-range graph and forward between the same pairs two ways. NDN delivers whenever any path exists right now — every Interest re-finds one. IP commits to a path and goes dark for a rediscovery interval each time a hop on it breaks. Both need connectivity to exist; the difference is what happens to the path that does. This is Panel C of #69 turned from a model into a measurement — including the real route-break rate λ it had only assumed.

A delivery vs velocity · N=40
NDN is flat; IP melts with speed

Pedestrian (0.5) to vehicular (20 m/s). NDN holds ~95% at every speed. IP loses every epoch it sits in repair on a stale route. The measured break rate λ (teal) is the honest version of #69's swept axis.

B delivery vs scale · v=5 m/s
Density feeds both — NDN converts it faster

At 12 nodes the graph is partitioned and both deliver ~⅓ — no discipline invents a path that isn't there. As density climbs, alternate paths appear; NDN uses each the instant it forms, IP still pays a rediscovery round-trip.

C NDN − IP delivery gap · velocity × scale
Where statelessness pays most

The advantage is largest where paths exist but churn fast — high speed, high density (bottom-right). At low density (left column) both are partition-limited, so the gap is small: NDN's edge is conditional on there being connectivity to track.
